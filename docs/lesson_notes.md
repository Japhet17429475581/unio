# Личные ДЗ и заметки студентов

Нажатие на любую пару студенческого расписания открывает `LessonNotesScreen`.
Можно сохранить текст (до 20 000 символов), прикрепить фотографии по 10 МБ,
снять фото камерой на Android/iOS и в поддерживаемом браузере, увеличить изображение, убрать отдельное
фото или удалить заметку. Цвета, карточки и основная кнопка используют
существующие компоненты и тему `brand.dart`.

## Хранение

Заметки **не отправляются в API и Redis**. `lib/backend/redis_db.py` — клиент
серверного Redis, а не кэш устройства. Бэкенд не изменён: серверное хранение
противоречило бы требованию сохранять личные фотографии только у пользователя.

- Android/iOS/desktop: каталог `unio_lesson_notes` в Application Documents.
  Текст и ссылки на фото записываются в JSON, фотографии — отдельными файлами.
- Web: локальная база IndexedDB `unio_lesson_notes`, без сетевых запросов.
- Запись сначала сохраняет новые фото, затем атомарно заменяет метаданные.
  Старые фотографии удаляются после успешного сохранения. При ошибке записи
  сохранённая версия заметки остаётся доступной.
- Это постоянные локальные данные, а не временный каталог кэша с TTL.
  Они переживают перезапуск, но удаляются вместе с данными приложения или сайта.
  Между устройствами синхронизации нет.

Ключ включает локальный профиль, группу, дату, время начала, предмет и тип пары.
Смена аудитории или имени преподавателя не отвязывает заметку. При переносе
пары на другое время/дату она считается другой парой.
Профиль портала определяется по логину; гостевой профиль — по токену сессии.
Повторный гостевой вход создаёт новый профиль и не открывает заметки старого.
Разные студенты одной группы не используют общее хранилище заметок.

Перед открытием системного выбора фото текст сохраняется. Для Android
сохраняется привязка к паре и обрабатывается `retrieveLostData()` после
перезапуска Activity. Разрешения для камеры/галереи добавлены в iOS Info.plist;
в macOS добавлено разрешение на чтение выбранных пользователем файлов.

Преподавательский маршрут по-прежнему открывает `TeacherLessonScreen`
с поиском аудитории; редактор заметок туда не подключён.

## Проверка

```
flutter test --no-pub test/lesson_notes_service_test.dart test/lesson_notes_screen_test.dart test/teacher_ui_test.dart
```

Новые платформенные плагины требуют полной пересборки приложения, а не только
hot reload. Работа системного выбора фото и камеры на реальном Android/iOS
проверяется отдельно от widget-тестов, где выбор фотографий подменён.

Документация плагинов: [image_picker](https://pub.dev/packages/image_picker),
[path_provider](https://pub.dev/packages/path_provider),
[idb_shim](https://pub.dev/packages/idb_shim).
