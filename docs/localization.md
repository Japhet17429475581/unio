# Языки интерфейса

В UNIO доступны русский и английский: **Настройки → Параметры → Язык**.
По нажатию открывается список «Русский / English». Выбор применяется сразу,
сохраняется на устройстве или в браузере и не зависит от аккаунта. По умолчанию
используется русский. Выход и удаление аккаунта сохраняют эту настройку, как тему.

Используется штатная локализация Flutter (`flutter_localizations`, `gen-l10n`),
без запросов к онлайн-переводчикам и без передачи пользовательского текста.
`lib/services/locale_service.dart` хранит выбор; оба `MaterialApp` в `lib/app.dart`
получают локаль и стандартные делегаты Material/Cupertino.
Открытые экраны подписаны на изменение локали; смена языка не сбрасывает навигацию,
поля ввода, выбранную неделю или сессию.

## Как добавлять тексты

1. Добавить одинаковый смысловой ключ в `lib/l10n/app_ru.arb` и `app_en.arb`.
2. Для подставляемых значений описать `placeholders` в русском шаблоне ARB.
3. Запустить `flutter gen-l10n` (или `flutter pub get`).
4. Использовать `l10n.<ключ>` из `locale_service.dart` вместо литерала в интерфейсе.
   Виджет должен читать `Localizations.localeOf(context)` в `build`, чтобы
   обновляться при смене языка, включая случаи с `const` родителями.
5. Запустить `flutter test test/localization_test.dart`.

Сгенерированные `app_localizations*.dart` не редактируются вручную.
Проверки сравнивают состав каталогов, параметры сообщений, наличие английского
перевода и сохранение выбора. Они также проверяют список выбора на экранах
320 и 430 px, смену языка дат, ошибок и гайда.

Для следующего языка нужен новый ARB-каталог, пункт списка выбора и разрешение
его кода в `LocaleService`. Переводы новых текстов нужно добавлять: движок
выбирает готовый перевод, но не придумывает его автоматически.

## Границы перевода

Переведены элементы Flutter-интерфейса: вход, знакомство, вкладки, расписание,
новости, заявления, заметки/фото, поиск преподавателей, настройки, управление
данными, безопасные сообщения и проверки форм. В PWA переключаются также
`html.lang`, заголовок страницы, сообщение загрузки и предложение обновления.
Сохранённый код языка отдельно зеркалируется для оболочки до запуска Flutter.

Исходные университетские данные не переводятся: ФИО, группы, предметы, статьи,
официальные результаты/статусы, динамические поля и варианты форм. Их значения
передаются порталу без изменений. Юридические документы и DOCX-шаблоны остаются
в оригинале на русском; их версии, SHA-256 и журнал согласий не меняются.
На английском экране документов это объяснено отдельно.

Нативный Android-виджет и уже запланированные системные уведомления в этот
перевод интерфейса не входят. Язык системных диалогов разрешений контролирует ОС.
Backend для выбора языка обновлять не требуется.
