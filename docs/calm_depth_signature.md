# UNIO Calm Depth + Signature — первый этап

По PDF и дополнению пользователя сначала изменено расписание. Остальные разделы
переводятся на новую систему после визуального подтверждения этого экрана.

## Дизайн

- Токены и локальная тема: `lib/config/calm_depth.dart`. Тема подключена только
  внутри расписания, поэтому не меняет оформление остальных вкладок и онбординга.
- Тёмная палитра: фон `#0B0F17`, карточки `#131924`, приподнятая поверхность
  `#1C2333`, границы `#263147`, текст `#F0F4F8`, вторичный текст `#8A99AD`.
- Светлая тема использует нейтральные поверхности. В обеих темах Signature
  сосредоточен в одной карточке следующей пары: градиент `#392B60 → #1D385C`,
  отдельный небольшой знак с округлым основанием, без букв поверх содержимого.
- Отступы 4/8/12/16/24, карточки 16, элементы управления 12 dp.
- Существующий Onest сохранён. Появление карточки и переходы длятся 220 мс;
  новые анимации отключаются при системном reduced motion.
- Свайпы и кнопка недели, выбор дня, таймер, переход к паре, обновление,
  офлайн-кэш, инструменты студента и преподавателя сохранены.
- Карточка показывает следующую пару сегодня, пропуская начавшиеся занятия.
  Преподаватель получает такой же обзор из уже загруженного расписания.
- Статусы отмены/переноса не выдумываются: текущая модель их не предоставляет.

Файлы интерфейса: `lib/screens/schedule_tab.dart`,
`lib/widgets/next_lesson_card.dart`, `lib/widgets/week_view.dart`,
`lib/widgets/day_card.dart`, `lib/widgets/lesson_row.dart`,
`lib/widgets/message.dart` (компактные состояния только внутри новой темы).

## Дополнение: вход преподавателя

По отдельному запросу пользователя добавлен вход по логину и паролю ВГСПУ.
Проверка выполняется существующим клиентом непосредственно на портале.
ФИО отдельно выбирает расписание; проверка роли сотрудника на портале пока
не реализована. Сервер UNIO не получает пароль.

Сессия преподавателя хранится одной записью в Secure Storage, отдельно от
студенческой. Сохранение происходит после успешной проверки портала. Старый
тестовый вход по ФИО не восстанавливается как авторизованная сессия: потребуется
войти через портал. Выход удаляет защищённую сессию преподавателя.

Файлы: `lib/app.dart`, `lib/screens/welcome_screen.dart` (только форма входа),
`lib/services/auth_service.dart`, `lib/services/secure_storage_service.dart`,
`lib/services/teachers_service.dart` (удалён вызов тестового входа).
Backend в этом этапе не изменялся.

## Этап 2 — после подтверждения расписания

Calm Depth стал общей темой рабочих экранов: университет, новости и статьи,
заявления/формы/статусы, настройки, заметки и инструменты преподавателя.
Нейтральные поверхности, компактные заголовки, единые кнопки и поля, карточки
радиусом 16 и отступы преимущественно 16. Signature остаётся у ближайшей пары.
Общая навигация и состояния загрузки/ошибок наследуют ту же тему.
Зачётка обёрнута в прежнюю тему; иллюстрации приветствия не изменены.

У переключателя темы удалена подпись «Включена/Выключена». Технические ошибки
отображаются через `user_messages.dart`: отдельно повторный вход, недоступность
сервиса, соединение и проверка данных. Произвольные исключения не показываются.

Гайд объединён в один круг «Гайд» (8 слайдов студенту, 6 преподавателю).
Остальные круги — новости из существующего API: по четыре круга на страницу,
превью фотографии, заголовок, краткий реальный текст и переход к полной статье.
Первое открытие полной статьи повторно не загружает уже полученные данные.
Новостной контроллер общий для двух недель; кешируются последние 20 заголовков
и ссылок, состояния просмотренных историй сохраняются локально. Сбой новостей
не блокирует расписание и гайд. Без изображения показывается аккуратная иконка.

Дополнительные проверки: `test/news_stories_test.dart`, `test/user_messages_test.dart`,
навигационные тесты и существующие проверки форм/настроек. Превью находятся в
`build/redesign-previews/`; это Flutter-рендеры с тестовыми данными, сетевые фотографии
в тестовом окружении заменяются иконками. Backend не менялся в этом этапе.

Аналитика использования описана отдельно в [mytracker.md](mytracker.md).
